# Sumud Journal website
This repository provides the Sumud Journal website. It is hosted on GitHub Pages and is automatically deployed on every push to the main-branch.

## Developing
Check out the repository to a new folder:
```bash
# clone the repository to a new folder sumud-journal
git clone git@github.com:haesena/sumud-journal.git
# switch to the newly created folder
cd sumud-journal
```

Before you start working, get the latest version:
```bash
git pull
```

To publish your changes, commit and push them to the main-branch:
```bash
# stage all changes
git add -A
# commit the changes
git commit -m "[description of your changes]"
# push the changes to GitHub
git push
```

The website is updated about a minute after the push. You can follow the deployment in the "Actions" tab of the repository on GitHub.
